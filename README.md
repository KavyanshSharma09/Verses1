⚔️ Verses1 – 1v1 Python Coding Battle Platform

Have you ever solved the same problem with a friend and wondered:
“Whose solution is actually better?”
Not just correct — but faster, more optimized, and smarter.

That curiosity led to Verses1, a platform that transforms coding into real-time battles of efficiency.

🚀 What is Verses1?
Verses1 is a 1v1 Python coding battle platform where developers compete by uploading code, entering a battle code, and benchmarking their solutions against each other.
It extends my earlier project PyOptimizer
(which analyzed a single file for performance bottlenecks) into a competitive coding arena.

✨ Features
Upload two Python files and compare them for efficiency
Real-time winner declaration based on optimization
Battle Lobby with unique codes so friends can join the same match
Battle History to track past duels and improvements
Hosted on Render with scalable backend support

🛠️ Tech Stack
Backend: Python, Django
Frontend: HTML, CSS, JavaScript
Optimization Engine: PyOptimizer (extended for Verses1)
Database: SQLite (upgradeable to PostgreSQL/MySQL)
Hosting: Render


⚡ Roadmap

Leaderboards & Global Battles
AI-powered challenge generation
Question Bank for structured practice
